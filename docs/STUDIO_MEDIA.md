# Game Studio media engine

The worker keeps uploaded originals unchanged. Image and audio edits produce new immutable objects; a draft refers to their IDs, and publication resolves only validated derivatives into stable media URLs. The functions in `game_studio/media.py` have no Django or database dependency.

## Worker contracts

| Function | Result |
| --- | --- |
| `inspect_upload(data, filename, kind)` | JSON-safe decoded metadata and SHA-256. `kind` is `tile`, `scene` or `audio`. |
| `render_tile(data, recipe=None)` | PNG bytes, RGBA, exactly 218×327. |
| `render_scene(data)` | Metadata-stripped lossless WebP bytes at the decoded source dimensions. |
| `process_audio(data, filename, recipe=None)` | `{data, extension: "wav", mime: "audio/wav", metadata, recipe}`. |
| `ContentStore(root=None).put(data, extension)` | `{key, sha256, size}`. Repeated bytes and extension identify the same immutable object. |
| `ContentStore.get(key)` | Original bytes after verifying the key's SHA-256. |

Names are display metadata; file extensions never select a decoder. Unsupported or invalid media raises `MediaError`. Invalid storage/configuration/integrity raises `StorageError`. Authentication and authorization belong to the API, including read access to originals and private derivatives.

## Image recipes and limits

Supported input is still PNG, JPEG or WebP. The pipeline rejects SVG, animated images, empty/corrupt files, compressed inputs over 16 MiB, dimensions over 8192 per side, and decoded images over 24 megapixels. EXIF orientation is applied; EXIF, ICC and other source metadata are not copied into derivatives.

Tile recipe fields:

```json
{
  "mode": "whole_tile",
  "fit": "contain",
  "zoom": 1,
  "x": 0.5,
  "y": 0.5,
  "gold": false,
  "background": "#00000000"
}
```

`mode` is `whole_tile` or `glyph`; `fit` is `contain` or `cover`. Zoom is 0.25–4; x/y anchors are 0–1. Glyph mode composites onto the approved ivory/gold ceramic body, which must have been generated by the existing artwork builder. It never modifies that body or source master. An inverse transform draws directly into the small tile output, so an extreme-aspect upload cannot force a huge resize-to-cover intermediate.

## Audio recipes and analysis

Input may be a decoded WAV, MP3, M4A, OGG or FLAC with one audio stream, no video, one or two channels, and source rate 8–96 kHz. Limits are 32 MiB compressed and 120 seconds decoded. FFmpeg receives a forced supported demuxer selected from binary magic, no shell, no network protocols, disabled MOV external references, a wall-clock deadline and a bounded PCM output. Final exports are 44.1 kHz PCM16 WAV for compatible playback. Derived file duration and frame counts refer to this 44.1 kHz timebase.

| Recipe field | Units and range |
| --- | --- |
| `trim_start`, `trim_end` | Seconds on decoded original; rounded to 44.1 kHz sample frames. End must follow start. |
| `loop_start`, `loop_end` | Seconds relative to the trimmed output; both null or both set within output bounds. |
| `fade_in`, `fade_out` | Seconds, frame-aligned. Their sum cannot exceed the trimmed duration. |
| `gain_db` | −60 to +12 dB. |
| `pan` | −1 to +1; mono constant-power pan, stereo balance attenuation. |
| `highpass_hz`, `lowpass_hz` | Zero disables; otherwise 20–20,000 Hz, with high-pass below low-pass. |
| `eq_low_db`, `eq_mid_db`, `eq_high_db` | −12 to +12 dB at 120, 1000 and 8000 Hz. |

An export that exceeds sample 0 dBFS is rejected before PCM conversion. This is not a guarantee against intersample peaks or clipping when several sounds are mixed. Analysis uses the exact PCM16 samples exported to the derivative. Metadata contains sample peak and RMS with dB equivalents; 384 aggregate waveform bins and per-channel min/max bins; duration, frame count and channel/rate metadata; and original/derivative hashes. For clips of at least three seconds, FFmpeg measures integrated loudness and true peak; very short clips report null with `loudness_status: "not_applicable_short_clip"`. Silent/gated levels use null, never non-finite JSON numbers.

## Runtime mixer

`web/assets/studio-v090/audio.js` preserves `window.MahjongWildAudio` and the saved `mw-sfx`, `mw-volume`, `mw-music`, `mw-music-volume` preferences. The legacy `mw-sfx` setting remains the master enable, including music. `configure(audio)` applies the exact version-one configuration from `game_studio/domain.py`; it resolves after applying the configuration while downloads continue separately. `setPhase("base" | "bonus")` selects music, with the base track as the default when bonus music is unset.

The graph provides Music, Reels, Wins and UI buses; event/clip gain; one final presentation gain (baseline 1.30); a maximum of 16 SFX voices; internal priorities that allow important wins/bonus to replace lower-priority sounds; modest music ducking during important wins; and bounded short-event cooldowns. These internal defaults are not advertised as editable schema fields. At most two fetch/decode tasks run together, the retained decoded cache is capped at 48 MiB and 24 buffers, and each file is bounded to 32 MiB with an eight-second fetch/decode cancellation deadline. Only assets used by the current release are preloaded. Configuration changes, hide, stop and mute invalidate stale playback. A broken or missing music file cannot delay configuration application or round settlement.

No physical-device listening or true-peak limiting claim follows from browser graph tests. Exact rendered derivatives can be auditioned in Studio; final loudness and loop quality should also be heard on the target devices.

## Private storage

Local mode uses `STUDIO_MEDIA_ROOT`, or an explicit `ContentStore(root)` for tests/restore. It is appropriate only when that path is durable or development-only. Writes create content-hash paths atomically and never replace an existing object. Traversal, unsupported suffixes, symlink escapes and hash corruption fail closed.

S3 mode requires all of `STUDIO_S3_BUCKET`, `STUDIO_S3_ENDPOINT`, `STUDIO_S3_ACCESS_KEY` and `STUDIO_S3_SECRET_KEY`; `STUDIO_S3_REGION` defaults to `auto`. The endpoint must be HTTPS. An incomplete S3 configuration does not silently fall back to local storage. S3 writes are conditional immutable creates; objects have no public ACL, and manifests store object keys rather than expiring URLs. Backups must retain object bytes as well as database references.

## Checks

```bash
python -m unittest discover -s tests -p test_studio_media.py -v
python tools/qa_studio_audio_v090.py
python tools/qa_studio_audio_v090.py --engine webkit
```

The media suite checks decode/recipe/size boundaries, non-destructive transforms, actual waveform/loudness output, extreme image aspect memory behavior, concurrency and storage integrity. Audio browser QA uses real OfflineAudioContext graphs to check the 1.30 amplitude ratio, exact mute, independent event/bus/master routing, music changes, priority/voice limits, stale load cancellation and nonblocking configuration while music is missing. It intentionally makes no hardware-volume or physical listening claim.
